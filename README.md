# راه‌اندازی گالری نقره محمودی

## اجرای سرور

Node.js نسخهٔ ۱۸ یا جدیدتر لازم است:

```powershell
npm install
npm start
```

فروشگاه و API باید از همین سرور در دسترس باشند. اطلاعات محصولات، تصاویر و سفارش‌ها در `data/store.json` ذخیره می‌شوند. در سرویس‌های میزبانی، `DATA_DIR` را به دیسک پایدار متصل کنید؛ فضای موقت سرویس ممکن است پس از راه‌اندازی مجدد پاک شود.

## ارسال سفارش به تلگرام

برای ارسال خودکار مشخصات مشتری و تصویر رسید:

1. یک ربات از طریق `@BotFather` بسازید و توکن آن را به‌صورت امن در متغیر محیطی `TELEGRAM_BOT_TOKEN` قرار دهید.
2. از حسابی که باید سفارش‌ها را دریافت کند، یک‌بار به ربات پیام `/start` بفرستید.
3. شناسهٔ عددی گفت‌وگوی دریافت‌کننده را در `TELEGRAM_CHAT_ID` قرار دهید. برای گفت‌وگوی خصوصی، شناسه را از به‌روزرسانی‌های ربات پس از `/start` بردارید.
4. سرور را با این متغیرها اجرا کنید و مطمئن شوید میزبان مقادیر را پس از راه‌اندازی مجدد نیز نگه می‌دارد.

نمونهٔ متغیرهای لازم:

```text
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
DATA_DIR=./data
```

توکن ربات را در فایل‌های سمت مرورگر یا مخزن عمومی قرار ندهید. اگر تنظیمات تلگرام ناقص یا ارسال ناموفق باشد، سفارش همچنان در سرور ذخیره می‌شود و فروشگاه خطای ارسال را به مشتری نشان می‌دهد.
